# Значки объектов — версия 3.3.0

Обновление существующей карты Аягоза. Данные MBTiles и база поиска не меняются.

Распакуйте ayagoz-icons-3.3.0.zip и загрузите в корень существующего GitHub-репозитория **семь файлов одним коммитом**:

1. server.js
2. package.json
3. style.json
4. poi-sprite.png
5. poi-sprite.json
6. poi-sprite@2x.png
7. poi-sprite@2x.json

Обязательно сохраняйте названия файлов, включая @2x. Файлы index.html, addresses.json и ayagoz-v3.mbtiles уже должны быть в репозитории от работающей версии 3.2.0. Их повторно загружать не нужно. Это пакет обновления, а не отдельный проект.

После коммита в существующем Render-сервисе выберите Manual Deploy → Deploy latest commit. Дождитесь успешного деплоя и обновите страницу через Ctrl+F5. /health должен показывать serverVersion=ayagoz-map-3.3.0, searchIndex=true, searchEntries=4761. Коммит в /health должен совпадать с успешным деплоем. Если файлы sprite не загружены вместе с сервером, запуск завершится явной ошибкой с именем отсутствующего файла.

При приближении с уровня 14 появятся значки:

- Синяя книга — школы, детсады, колледжи, университеты и библиотеки.
- Красный крест — медицина и аптеки.
- Золотой магазин — магазины, кафе, рестораны, банки и банкоматы.
- Серое предприятие — объекты с industrial, craft или office.
- Фиолетовый автомобиль — заправки, парковки, автомойки, автостанции и такси.
- Зелёное дерево — парки и некоторые спортивные/досуговые объекты.
- Бирюзовая метка — остальные POI.

Категория определяется только по существующим тегам OSM. Значки не добавляют отсутствующие в карте организации. Иконки появляются с z14, названия — с z15; MapLibre предотвращает пересечения. Нажатие на значок открывает имеющуюся карточку объекта. Поиск и выбор «Откуда»/«Куда» сохранены.

Файлы @2x предназначены для экранов высокой плотности, включая телефоны. Sprite PNG и JSON выдаются с собственного сервера, а style.json содержит абсолютный URL sprite — эти ресурсы не зависят от JavaScript веб-страницы и смогут использоваться будущим MapLibre-клиентом Android. Интеграция Flutter пока не реализована.

Локально подтверждены: выдача четырёх файлов sprite, корректность PNG/JSON, абсолютный HTTPS-адрес за прокси, API поиска по реальным данным и неизменность всех 1154 тайлов. Стиль прошёл валидацию, сам атлас значков визуально осмотрен. Раскладка значков на живой карте телефона ещё требует проверки после деплоя. Результаты тестов — icons-test-results.txt.

Сначала найдите «Школа №5», проверьте синюю книгу при приближении, затем найдите «Сұңқар» и проверьте значок магазина. Проверьте отсутствие ошибок 404 в Console/Network и работу обеих точек поездки на Android.
